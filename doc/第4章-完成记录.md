## 版本与兼容处理

- 当前项目为 Java 21、Spring Boot 4.1.0、springdoc 3.1.0，使用项目已有的 com.baizhukui:knife4j-openapi3-boot4-spring-boot-starter:5.8.0。
- MyBatis-Plus 3.5.18.1 的 Service 类位于 com.baomidou.mybatisplus.spring.service，模板按该版本生成，未照搬教程旧包名。
- 使用 mybatis-plus-jsqlparser-4.9，解决默认新版 SQL 解析器与 PageHelper 共存时的 NoSuchMethodError。
- 为兼容若依旧系统使用 Date 的契约，保留 BaseEntity；护理实体与新生成普通实体使用 NursingEntity，公共时间字段为 LocalDateTime。searchValue、params 排除数据库映射。
- 查询列表保留现有 XML 条件，避免丢失筛选功能；MP 负责单表主键查询、新增、更新和删除。主子表详情模板仍使用原 XML 关联映射。
- 旧系统的 Date 实体没有全局迁移；本章要求的新护理实体及生成模板使用 LocalDateTime。
- 前端“系统接口”的 doc.html 地址及已有 LocalDateTime 选项保留。重新生成的三套前端页面和 API 与原文件一致，因此 Git 中没有额外页面差异。
- 未执行生成菜单 SQL，未变更业务表结构，也未更新数据库中已导入的生成元数据。新导入表采用新默认映射；旧表可在生成器字段配置中选择 LocalDateTime。
